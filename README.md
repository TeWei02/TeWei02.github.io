# TeWei02.github.io

Personal website and portfolio of **柯德瑋 (Te-Wei Ko)** — CS student at Southern Taiwan University of Science and Technology (STUST), exploring the essence of "experience" through affective computing, interaction design, and semantic perception.

## Highlights

- **Project H.O.L.O.** — multi-sensory story reconstruction engine (ModernReader)
- **qbridge** — quantum computing simulator in C++ / Python
- **sensory-shield** — neurodiversity-friendly Chrome extension
- **iq-analysis-bot** — 48-question interactive IQ analysis quiz (live on GitHub Pages)
- **wildstream-guardian** — river water-quality monitoring platform (FastAPI)
- **Real-time Packet Monitoring** — traffic statistics system in Python

## Features

- Dark / Light theme toggle
- Bilingual layout (Traditional Chinese / English)
- SEO: Open Graph, Twitter Card, JSON-LD structured data
- Project showcase with live links
- Responsive single-page design

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- CSS Custom Properties for theming
